# 01. Python과 객체지향 입문

"쓸 줄 아는 Python"에서 "구조를 설계할 수 있는 Python"으로 넘어가는 단계. 클래스를 직접 설계해 보는 것이 핵심이다.

## 학습 목표

- Python이 변수와 객체를 어떻게 다루는지 설명할 수 있다.
- 모듈과 패키지로 코드를 나눌 수 있다.
- 클래스를 처음부터 직접 설계할 수 있다 (상속, 캡슐화, 다형성).
- pytest로 테스트를 작성할 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | Python 실행 방식 | 인터프리터, REPL vs 스크립트, 변수는 이름표(객체 참조), `is` vs `==`, `id()` |
| s02 | 자료형 내부 | mutable vs immutable, list/tuple/dict/set의 동작, 얕은 복사 vs 깊은 복사 |
| s03 | 함수 | 인자 전달 방식, 기본값 함정, `*args`/`**kwargs`, 스코프(LEGB), 일급 함수, 람다 |
| s04 | 반복의 도구 | 컴프리헨션, 이터레이터, 제너레이터 (`yield`) |
| s05 | 모듈과 패키지 | import 동작 원리, `if __name__ == "__main__"`, 패키지 구조, 외부 패키지 설치 |
| s06 | 예외 처리와 파일 | try/except/else/finally, 사용자 정의 예외, 파일 입출력, `with` |
