# 00. 개발 환경과 도구

개발자가 매일 쓰는 도구에 익숙해지는 단계.

## 학습 목표

- 터미널에서 파일과 폴더를 다룰 수 있다.
- Git으로 변경 사항을 기록하고 GitHub에 올릴 수 있다.
- Python 가상환경을 만들고 패키지를 설치할 수 있다.
- WSL로 Linux 환경을 쓸 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | 터미널과 셸 | 파일 시스템과 경로(절대/상대), 기본 명령어(cd, ls, mkdir, cp, mv, rm), PowerShell vs Bash, 환경변수와 PATH |
| s02 | Git과 GitHub | 저장소, 스테이징과 커밋, log/diff, .gitignore, 원격 저장소와 push. **이 저장소 첫 커밋 & GitHub 공개 저장소 연결** |
| s03 | 개발 도구 | VS Code 사용법과 확장, Python 가상환경(uv), WSL 설치와 Linux 맛보기, 마크다운 문법 |

## 체크리스트

- [x] 터미널만으로 폴더를 만들고, 파일을 복사·이동·삭제할 수 있다
- [ ] PATH가 무엇이고 왜 필요한지 설명할 수 있다
- [ ] `git add` / `commit` / `push`의 차이를 설명할 수 있다
- [ ] 이 저장소를 GitHub에 올렸다
- [ ] 가상환경을 만들고 패키지를 설치했다
- [ ] WSL에서 Linux 명령어를 실행해 봤다
