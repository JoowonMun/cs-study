개념을 내 말로 정리하고, 직접 코드를 짜고, 설명할 수 있을 때 다음 단계로 넘어갑니다.

## 학습 원칙

1. **개념 → 실습 → 내 말로 설명.** 설명할 수 없으면 아직 모르는 것이다.
2. **코드는 직접 짠다.** AI는 설명·힌트·퀴즈·리뷰만 맡는다.
3. **작게, 자주 커밋한다.** 커밋 기록이 곧 학습 기록이다.
