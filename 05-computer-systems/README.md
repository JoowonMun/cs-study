# 05. 컴퓨터 구조와 운영체제

코드가 하드웨어와 운영체제 위에서 실제로 어떻게 돌아가는지 이해하는 단계. "왜 numpy가 빠른가", "왜 딥러닝에 GPU를 쓰는가"에 답할 수 있게 된다.

## 학습 목표

- CPU, 메모리, 캐시가 프로그램 성능에 어떤 영향을 주는지 설명할 수 있다.
- 프로세스, 스레드, 동시성 문제를 설명할 수 있다.
- Python에서 멀티프로세싱, 멀티스레딩, 비동기 중 무엇을 쓸지 판단할 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | 데이터 표현 | 2진수/16진수, 정수 표현(2의 보수), 부동소수점과 수치 오차 (`0.1 + 0.2 != 0.3`) |
| s02 | 컴퓨터 구성과 CPU | 폰 노이만 구조, CPU·메모리·버스, 명령어 사이클, 레지스터, 파이프라이닝 |
| s03 | 메모리 계층과 캐시 | 레지스터 → 캐시 → RAM → 디스크, 지역성, numpy가 빠른 이유 |
| s04 | GPU가 빠른 이유 | CPU vs GPU, SIMD와 대규모 병렬, 행렬 연산과 딥러닝 |
| s05 | 운영체제와 프로세스 | 운영체제의 역할, 커널, 프로세스 vs 스레드, 컨텍스트 스위칭 |
| s06 | 스케줄링과 동기화 | CPU 스케줄링 알고리즘, 경쟁 상태, 뮤텍스와 세마포어, 교착상태 |
| s07 | 메모리 관리 | 가상 메모리, 페이징, 페이지 교체 알고리즘(FIFO, LRU) |
| s08 | 파일 시스템과 Python 병렬 처리 | 파일 시스템 기초, `threading` vs `multiprocessing`, GIL |
| s09 | 비동기 프로그래밍 | `asyncio`, 이벤트 루프, I/O-bound vs CPU-bound |
