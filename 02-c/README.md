# 02. C 언어와 메모리

Python이 대신 해 주던 일(메모리 관리, 타입, 컴파일)을 직접 해 보는 단계. 포인터를 이해하면 컴퓨터 구조와 운영체제가 훨씬 잘 보인다.

## 학습 목표

- 소스 코드가 실행 파일이 되는 과정을 설명할 수 있다.
- 포인터로 메모리를 직접 다룰 수 있다.
- 스택과 힙의 차이를 알고 동적 메모리를 안전하게 쓸 수 있다.
- C 코드를 읽고 출력 결과를 예측할 수 있다.

## 체크리스트

- [ ] 컴파일 과정 4단계를 설명할 수 있다
- [ ] `a[i]`와 `*(a+i)`가 같은 이유를 설명할 수 있다
- [ ] swap 함수를 포인터로 구현할 수 있다
- [ ] malloc으로 할당한 메모리를 free하지 않으면 무슨 일이 생기는지 설명할 수 있다
- [ ] 포인터가 섞인 코드의 출력 결과를 손으로 추적할 수 있다
