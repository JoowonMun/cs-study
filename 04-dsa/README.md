# 04. 자료구조와 알고리즘

데이터를 어떻게 담고 처리해야 빠른지 배우는 단계. 주로 Python으로 구현하고, 메모리 구조가 중요한 부분은 C로도 짜 본다.

## 학습 목표

- 코드의 시간·공간 복잡도를 Big-O로 분석할 수 있다.
- 주요 자료구조를 직접 구현하고, 상황에 맞게 고를 수 있다.
- 정렬, 탐색, 그래프 탐색 알고리즘을 구현할 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | 알고리즘 분석 | 시간·공간 복잡도, Big-O, 최선/평균/최악 |
| s02 | 배열과 동적 배열 | 정적 배열 vs 동적 배열, Python list 내부 동작, 분할 상환 분석 |
| s03 | 연결 리스트 | 단일/이중 연결 리스트 (Python + C 구현) |

| s05 | 해시 테이블 | 해시 함수, 충돌 처리(체이닝, 개방 주소법), Python dict 내부 |

## 체크리스트

- [ ] 이중 for문이 O(n²)인 이유를 설명할 수 있다
- [ ] dict 조회가 평균 O(1)인 이유를 설명할 수 있다
- [ ] 연결 리스트, 스택, 큐, BST를 직접 구현했다
- [ ] 퀵 정렬과 병합 정렬의 차이를 설명할 수 있다
- [ ] BFS와 DFS를 직접 구현했다
- [ ] 문제를 보고 어떤 자료구조를 쓸지 판단할 수 있다
