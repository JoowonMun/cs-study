# 03. Java와 객체지향 심화

정적 타입 언어로 객체지향을 제대로 굳히는 단계. 01에서 Python으로 배운 OOP를 Java에서는 어떻게 하는지 계속 비교한다.

## 학습 목표

- JVM 위에서 Java 프로그램이 실행되는 과정을 설명할 수 있다.
- 접근 제어자, 인터페이스, 추상 클래스로 객체지향 설계를 할 수 있다.
- 오버로딩과 오버라이딩, 다형성이 들어간 코드를 읽고 결과를 예측할 수 있다.
- 컬렉션과 제네릭을 쓸 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | Java 실행 구조 | JDK/JRE/JVM, 바이트코드, 정적 타입, 개발 환경 설치, Hello World |
| s02 | 기본 문법 | 기본형 vs 참조형, 문자열(`String`, `==` vs `equals`), 배열, 제어문 |
| s03 | 클래스와 객체 | 필드와 메서드, 생성자, `this`, 접근 제어자(public/protected/default/private) |
| s04 | static과 패키지 | `static`, `final`, 패키지와 import |
| s05 | 상속 | `extends`, `super`, 오버라이딩 vs 오버로딩, 업캐스팅/다운캐스팅 |
| s06 | 추상화와 다형성 | 추상 클래스 vs 인터페이스, 다형성, Python ABC와 비교 |
| s07 | 예외 처리 | try/catch/finally, checked vs unchecked 예외, throws |
| s08 | 컬렉션과 제네릭 | List/Set/Map, ArrayList vs LinkedList, 제네릭 |
| s09 | 모던 Java 맛보기 | 람다, 스트림 API, 빌드 도구(Gradle) 개념 |
| s10 | 종합 실습 | **인터페이스로 설계한 작은 프로그램** (예: 여러 결제 수단을 다형성으로 처리) |

## 체크리스트

- [ ] Java가 "한 번 작성하면 어디서나 실행된다"는 말의 의미를 설명할 수 있다
- [ ] 추상 클래스와 인터페이스를 언제 쓰는지 구분할 수 있다
- [ ] 부모 타입 변수에 자식 객체를 넣었을 때 어떤 메서드가 호출되는지 예측할 수 있다
- [ ] 같은 설계를 Python과 Java로 각각 구현해 보고 차이를 정리했다
