# 07. 데이터베이스

데이터를 안전하고 효율적으로 저장하고 꺼내는 단계. SQL을 쓰는 것을 넘어 DB가 내부에서 어떻게 동작하는지 이해하는 것이 목표다.

## 학습 목표

- 관계형 데이터베이스를 설계하고 정규화할 수 있다.
- 조인, 서브쿼리, 집계를 포함한 SQL을 작성할 수 있다.
- 트랜잭션과 인덱스의 원리를 설명할 수 있다.
- Python 애플리케이션에 DB를 연결할 수 있다.

## 세션 계획

| # | 주제 | 내용 |
|---|---|---|
| s01 | DB 기초 | DB와 DBMS, 관계형 모델, 키(기본키, 외래키, 후보키), SQLite 시작 |
| s02 | SQL 기본 | DDL(CREATE/ALTER/DROP), DML(SELECT/INSERT/UPDATE/DELETE), DCL(GRANT/REVOKE) |
| s03 | SQL 심화 | 조인(INNER/LEFT/OUTER), 서브쿼리, GROUP BY/HAVING, 윈도 함수 |
| s04 | 설계와 정규화 | ERD, 제1~3정규형과 BCNF, 이상 현상, 반정규화 |
| s05 | 트랜잭션 | ACID, 커밋과 롤백, 격리 수준, 동시성 문제 |
| s06 | 인덱스 | B-Tree 인덱스, 실행 계획(EXPLAIN), 인덱스가 오히려 느린 경우 |
| s07 | Python과 DB | `sqlite3`, ORM 개념, SQLAlchemy |
| s08 | API에 DB 연결 | 06에서 만든 CRUD API에 DB 연결 |
| s09 | NoSQL과 벡터 DB | 문서형/키-값 DB, 임베딩과 유사도 검색, 벡터 DB 개념 |

## 체크리스트

- [ ] 요구사항을 보고 ERD를 그리고 테이블을 설계할 수 있다
- [ ] 정규화를 하는 이유와 이상 현상을 설명할 수 있다
- [ ] LEFT JOIN과 INNER JOIN의 결과 차이를 예측할 수 있다
- [ ] 트랜잭션이 없으면 생기는 문제를 예로 들어 설명할 수 있다
- [ ] 06의 API가 DB에 데이터를 저장하도록 바꿨다
- [ ] 벡터 DB가 RAG에서 어떤 역할을 하는지 설명할 수 있다
